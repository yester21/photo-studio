# 포토 스튜디오 (Photo Studio)

브라우저에서 바로 쓰는 온라인 사진 편집기입니다.
**서버가 전혀 없는 순수 정적 웹앱**으로, 사진을 열어도 어디로도 전송되지 않습니다 —
모든 편집은 사용자의 브라우저 안에서만 처리되고, 저장도 사용자 기기로 내려받는 방식입니다.

- 의존성 0 · 빌드 과정 0 · 웹폰트 0 (전체 용량 약 240KB)
- 실행은 정적 파일 서빙만으로 충분 (Cloudflare Pages 무료 플랜 권장)

---

## 화면 구성

상단 모드 탭 6개로 구성됩니다. **편집기 · 일괄 · 결합 · 분할 · GIF · 도구**

### 편집기

사진 한 장을 고解像도로 편집하는 메인 화면. 왼쪽 툴 레일 11종 + 오른쪽 옵션 패널 구조입니다.

- **파일**: 드래그앤드롭 · 클립보드 붙여넣기(Ctrl+V) · 파일 열기 (JPG/PNG/WebP/GIF)
  - 36MP 초과 이미지는 열 때 편집용으로 자동 축소
  - 저장: JPG(품질 조절) / PNG(투명 유지) / WebP — 미리보기와 출력이 항상 동일
- **자르기**: 자유 · 원본 비율 · 1:1 · 4:3 · 3:4 · 16:9 · 9:16 · **원형 자르기**(PNG 배경 투명)
  - 비율 고정 상태에서 핸들을 밖으로 밀면 비율을 유지한 채 이미지 경계에 자동 클램프
- **회전 · 뒤집기**: 90° 좌우 회전, 상하·좌우 뒤집기, **기울기 보정**(±15°, 원본 크기 유지 커버 크롭)
- **크기 조정**: 리사이즈(비율 잠금, 단계 축소로 품질 확보), 여백 확장(색상 지정 또는 투명)
- **색 보정** (슬라이더 11종): 노출 · 밝기 · 명암 · 채도 · 자연 선명도 · 색조 · 감마 · 하이라이트 · 섀도 · 색온도 · 틴트
  - **자동 레벨 / 자동 명암** (히스토그램 0.4% 클리핑 스트레칭)
  - **자동 화이트밸런스** (회색 세계 기준, 다시 누르면 해제)
- **커브 · 레벨**: RGB/R/G/B 채널별 톤 커브 — 히스토그램 배경, 클릭으로 포인트 추가,
  드래그 조절, 더블클릭 삭제 (모노톤 스플라인으로 계단 현상 없음). 블랙/화이트 포인트·중간값 슬라이더
- **효과**: 선명하게(언샵마스크) · 부드럽게 · 비네트 · 블룸 · 역광 보정
- **모드 · 프리셋**: 흑백 · 세피아 · 네거티브, 필름 프리셋 5종(비비드 · 필름 웜 · 청량 · 빈티지 · 무드)
- **부분 보정**: 타원 드래그로 영역을 지정해 그 부분만 밝기·노출·채도·명암 조절 (이동·리사이즈·페더 지원, 비파괴)
- **아웃포커스**: 타원 밖만 흐리게 하는 배경 흐림
- **브러시 · 지우개**: 색·두께·투명도. 지우개는 그린 개체만 지웁니다(사진 손상 없음)
- **도형**: 직선 · 화살표 · 사각 · 타원 (선 색·두께·채우기)
- **텍스트**: 클릭으로 배치, 드래그 이동, 폰트 6종 · 크기 · 굵기 · 색 · 외곽선 · 그림자, 여러 줄 지원
- **클론 스탬프**: Alt+클릭으로 복제 지점을 찍고 드래그해 덮기 (페더 브러시)
- **잡티 제거**: 클릭 한 번으로 주변과 가장 비슷한 8방향 패치를 찾아 덮기
- **적목 제거**: 붉은 기운만 선택적으로 제거
- **모자이크**: 블록 강도 조절 가능한 픽셀화 브러시
- **편집 공통**: 40단계 Undo/Redo(Ctrl+Z / Ctrl+Shift+Z), 누르는 동안 원본 보기,
  휠 줌(커서 앵커) · 드래그 팬 · 화면 맞춤(Ctrl+0), Ctrl+S 저장, 개체는 벡터로 유지되다가
  자르기·회전 등 프레임 연산 시 이미지에 반영

### 일괄

여러 사진에 **색 보정 5종(노출·밝기·명암·채도·색온도) + 텍스트 워터마크**를 한 번에 적용합니다.

- 워터마크: 9위치(모서리·중앙), 크기는 이미지 크기에 비례해 자동 확대, 투명도·색·그림자
- 출력 포맷은 각 파일 원본을 유지(JPG→JPG, PNG→PNG), 결과는 **ZIP 한 파일**로 내려받기
- 포맷 변환·압축·리사이즈는 이 앱의 역할이 아닙니다(별도 이미지 툴 담당)

### 결합

여러 사진을 한 장으로 이어 붙입니다.

- 배치: **가로**(높이 통일) / **세로**(너비 통일) / **그리드**(균등 셀에 맞춰 중앙 배치, 열 수 2~5)
- 간격(px) · 배경색 지정, 실시간 미리보기, JPG/PNG 내려받기

### 분할

한 장의 사진을 행×열 조각으로 자릅니다. (SNS 프로필 그리드용)

- 나머지 픽셀은 앞쪽 조각에 분배 — 원본이 한 픽셀도 손실 없이 덮입니다
- PNG/JPG 선택, 결과는 **ZIP**으로 내려받기

### GIF

여러 사진을 프레임으로 하는 애니메이션 GIF를 만듭니다.

- 프레임 순서 재정렬(↑↓), 폭 리스케일(원본/800/640/480/320), 프레임 지연(20~2000ms), 무한/1회 반복
- 재생 미리보기 내장
- 인코더를 직접 구현했습니다(median-cut 256색 양자화 + LZW) — 외부 라이브러리 0

### 도구

- **색상 선택기**: 사진을 열고 클릭하면 HEX/RGB/HSL을 보여주고 복사합니다.
  7배 루페 내장. Chrome/Edge에서는 **EyeDropper API**로 화면 전체에서도 추출 가능
- **화면 캡처**: 화면·창·탭을 캡처해 편집기로 바로 불러옵니다
- **이름 바꾸기**: 여러 파일을 "접두어 + 시작 번호 + 자릿수" 규칙으로 일괄 변경 (ZIP)
  - 이미지가 아니어도 됩니다(txt 등 임의 파일 지원)

## 실행 방법

ES 모듈을 사용하므로 정적 서버로 서빙해야 합니다(`file://` 직접 열기 불가).

```bash
# 저장소 클론
git clone https://github.com/yester21/photo-studio.git
cd photo-studio

# 아무 정적 서버나 — 예:
python -m http.server 3350 --bind 127.0.0.1
# 또는
npx serve .
```

브라우저에서 `http://127.0.0.1:3350` 접속.

## 배포 (Cloudflare Pages)

순수 정적 앱이라 무료 플랜으로 충분합니다(요청 수·대역폭 무제한).

1. Cloudflare 대시보드 → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. 저장소 `yester21/photo-studio` 선택
3. 빌드 설정 — Framework preset: **None** · Build command: **(없음)** · Build output directory: **/**
4. Save and Deploy → `*.pages.dev` 주소 발급 → 필요 시 Custom domains 연결

### 업데이트 시 캐시 주의 (중요)

브라우저는 ES 모듈을 적극적으로 캐시합니다. 소스를 수정한 후에는
`index.html`의 `<script src="js/app.js?v=…">` 쿼리와, 변경된 모듈을 import하는
모든 경로의 `?v=` 값을 **같은 값으로 함께** 올려야 사용자가 새 버전을 받습니다.
(하나라도 빠지면 섞인 버전이 로드됩니다.)

## 프로젝트 구조

```
photo-studio/
├── index.html          # 전체 마크업 (모드 탭 6개 페이지 포함)
├── assets/app.css      # 디자인 토큰 + 전체 스타일
└── js/
    ├── app.js          # 편집기 UI 배선 (슬라이더·자르기 오버레이·줌/팬·단축키)
    ├── modes.js        # 상단 모드 탭 전환 + 각 모드 초기화
    ├── engine.js       # 문서 상태·40단계 히스토리·열기/저장
    ├── pipeline.js     # 픽셀 파이프라인 (LUT 톤보정·커브·부분 보정 마스크·효과·지오메트리)
    ├── curves.js       # 톤 커브 스플라인 + 커브 편집기 UI
    ├── tools.js        # 편집 도구 포인터 머신 (브러시·클론·힐링 등 11종)
    ├── objects.js      # 그리기 개체 레이어 (스트로크·도형·텍스트)
    ├── batch.js        # 일괄 편집
    ├── combine.js      # 결합
    ├── split.js        # 분할
    ├── gifmode.js      # GIF 만들기 UI
    ├── gifenc.js       # GIF89a 인코더 (median-cut + LZW, 자체 구현)
    ├── toolsmode.js    # 도구 탭 (색상 선택기·화면 캡처·이름 바꾸기)
    ├── filelist.js     # 모드 공통 다중 파일 목록
    └── zip.js          # 무압축 ZIP 라이터 (CRC32·UTF-8 파일명)
```

## 아키텍처 요약 (개발자용)

- **base + adj + objects 3분리**
  - `base`: 자르기·회전·브러시 등 **파괴적 연산의 결과 캔버스**
  - `adj`: 커브·레벨·WB·부분 보정 등 **비파괴 색보정 파라미터** (매 프레임 LUT 재계산)
  - `objects`: 스트로크·도형·텍스트 **벡터 개체** — 자르기 같은 프레임 연산 전에 base에 베이크
- **히스토리**: `{base 참조, adj·objects structuredClone}` 최대 40단계. 슬라이더는 커밋(change) 시점에 1스텝
- **단일 파이프라인**: 미리보기와 저장이 같은 `renderTo()`를 쓰므로 화면과 출력이 항상 동일
- **성능**: 미리보기는 뷰포트 크기로 축소 렌더(원본은 저장 시에만 풀 해상도 처리),
  개체 오버레이는 버전 카운터 캐시, 부분 보정은 타원 그라디언트 마스크 합성

## 브라우저 지원

대략 2022년 이후 버전의 Chrome / Edge / Firefox / Safari.
(`createImageBitmap`, `structuredClone`, Canvas 2D 사용. EyeDropper·화면 캡처는 Chromium 계열에서 동작)

## 개인정보

이 앱은 네트워크 요청을 하나도 하지 않습니다. 열어서 편집한 이미지·파일은
사용자의 기기를 떠나지 않으며, 서버에 저장되는 것도 없습니다. 네트워크 탭에서 직접 확인할 수 있습니다.
